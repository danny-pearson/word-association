# Word Association Game

A simple word association guessing game in the style of Pinpoint.

Each puzzle has one answer and five clues. You start with a single clue, and
another is revealed every time you guess wrong. The fewer clues you need, the
better you have done.

Puzzles will be generated by an LLM rather than written by hand, so the library can
keep topping itself up in the background. Hopefully this will enable continuous play
(as opposed to a single puzzle per day) but this is probably ambitious when based on
LLM output.

Currently an experimental work in progress, and a toy project to be played by
students on a functional english course.
